# Учебный frontend-проект
# SuperTutor — каталог репетиторов и курсов

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

SuperTutor — учебный многостраничный сайт-каталог репетиторов и курсов:
пользователь выбирает предмет (математика, физика, химия, биология,
английский язык, литература, программирование, финансовая грамотность,
музыка и подготовка к экзаменам), смотрит карточку курса и оставляет
заявку на консультацию или запись.

## Структура проекта
 
- `index.html` — главная страница: hero-блок, преимущества, популярные курсы;
- `catalog.html` — каталог курсов: фильтры по категории и цене, сетка из 10 карточек с изображениями;
- `product.html` — страница курса «Математика»: описание, таблица характеристик, бейдж, кнопка записи;
- `order.html` — отдельная страница с формой заявки;
- `contacts.html` — контактная информация и форма обратной связи;
- `css/style.css` — файл стилей;
- `js/main.js` — открытие/закрытие модального окна и валидация формы;
- `images/` — фотографии курсов (`math.jpg`, `phys.jpg`, `chem.jpg`, `bio.jpg`, `eng.jpg`, `lit.jpg`, `prog.jpg`, `fin.jpg`, `mus.jpg`, `suc.jpg`);
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Дополнительные элементы

- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.
